# UNCUT.EXE

GALANACCI OS copy of the Video Journal Room. The app keeps the reconstructed
workspace, CRT masking and channel transitions, episode archive, and CRT sound.
The OS window supplies the close button; closing it unloads the YouTube player
and stops the local CRT sound.

`assets/episodes.json` is a snapshot of the PoG repository's
`data/documentary.json` (last source sync: 2026-09-03). When new weekly episodes
are added there, refresh this local copy before publishing GALANACCI OS.
Episode titles, summaries, the original 3D scan, and the videos are archival
content and can contain PoG references. The UNCUT app interface itself uses
GALANACCI OS branding.

The bundled Three.js files are from the PoG Video Journal viewer. Their license
is in `vendor/three/LICENSE`.
