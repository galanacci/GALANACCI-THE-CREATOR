SPOTIFY_DOWNLOADER.EXE

A local Python script that downloads playlist matches as MP3 files, with metadata, album artwork and available lyrics. This page provides the script; the download runs on your computer.

DOWNLOAD WINDOWS LAUNCHER ↓

Extract the ZIP, then double-click START_DOWNLOADER.bat. Paste your playlist URL, choose a folder and click Download playlist. Python and FFmpeg are required; spotDL is installed automatically into a local virtual environment.

DOWNLOAD PYTHON SCRIPT ↓

1 / PREPARE

Install Python and FFmpeg. Confirm ffmpeg -version works in your terminal. A virtual environment keeps spotDL separate from other projects:

py -3.12 -m venv .venv
.\.venv\Scripts\python.exe download_playlist.py

2 / SET YOUR PLAYLIST

Open the downloaded script and replace the placeholder at the top:

PLAYLIST_URL = "YOUR_SPOTIFY_PLAYLIST_URL_HERE"

3 / RUN

Run the Python command above from the folder containing the script. It installs spotDL via pip if missing. Files go directly into Downloaded_Music alongside the script.

spotDL matches Spotify metadata to audio providers such as YouTube; it does not extract Spotify's audio stream. Artwork and lyrics depend on availability. Some providers also need Deno; see the official setup guide.
