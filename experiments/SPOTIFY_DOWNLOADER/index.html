GALANACCI / WINDOWS TOOL

SPOTIFY_DOWNLOADER.EXE

Save Spotify playlists or exact YouTube videos and playlists as MP3 files—including your favourite live performances.

DOWNLOAD WINDOWS LAUNCHER ↓

  1. DOWNLOAD & EXTRACT

    Download the ZIP above. Right-click it, choose Extract All, then open the extracted folder.

  2. OPEN THE LAUNCHER

    Double-click START_DOWNLOADER.bat. Keep the files together in the extracted folder.

  3. PASTE & DOWNLOAD

    Paste a Spotify playlist or YouTube video/playlist link, choose where to save the files, then click Download / Resume audio. Use Open music folder to find your MP3s.

Already downloaded it? Open START_DOWNLOADER.bat whenever you need it. No script editing or terminal commands required.

Interrupted playlist? Use the same link and music folder, then click Download / Resume audio. Every Spotify run scans existing MP3 metadata and filename track IDs first, then skips completed tracks. Failed tracks remain eligible next time. Detailed provider errors are saved in spotify-download-details.log in your music folder.

YouTube links keep the exact performance you chose. A video link downloads that video only; use a YouTube playlist link to download the whole playlist.

The first download sets up the required tools automatically and may take longer. By default, music is saved in Downloaded_Music beside the launcher. Cancelling keeps completed downloads.

FIRST-TIME SETUP & HELP

You need Python 3.12 with Tcl/Tk and FFmpeg installed on Windows. FFmpeg must be available on PATH. If the launcher is already working, no further setup is needed.

In Spotify, use Share → Copy link to playlist. On YouTube, copy the video's Share link or the playlist's own link. If a download fails, check the launcher's log.

Spotify uses spotDL to match tracks, with artwork and available lyrics. YouTube uses yt-dlp directly, preserving the selected version and embedding available video metadata and its thumbnail. Spotify's Deno prerequisite is set up automatically when missing.
