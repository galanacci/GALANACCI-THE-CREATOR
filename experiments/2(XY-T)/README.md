# PoG XY+T Prototype V19 — Expanded Zoom

Built from V18.

## Change
- Expanded orbit camera zoom range.
- Minimum camera distance: **2.15** (previously 4.1).
- Maximum camera distance: **24.0** (previously 12.5).
- Mobile pinch-to-zoom uses the new full range.
- Desktop Shift + wheel uses the new full range.
- Reset View still returns to the established 7.1 default.

All V18 mobile transport, video upload, mask toggle, Motion/Silhouette modes, trail controls, and temporal-volume behaviour are preserved.


## V20 update
- Bounding box / cube outline changed to the PoG purple accent (#9B70DF).
- Slightly increased outline opacity for a clearer accent read.


## V21 update
- Bounding box / cube outline removed entirely for a cleaner floating temporal form.
